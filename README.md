# Бот «Потерялся / Нашёлся» — доска объявлений

Бот для Telegram-канала **@malakhovka_in_the_lens**. Принимает заявки о пропавших
и найденных животных, отдаёт их на модерацию и публикует карточки в канал.

## Возможности (MVP)

- Приём заявки пошагово: `/lost` / `/found` или кнопки.
- Сбор фото (до 3), вида, породы/окраса, пола, возраста, района, места, даты, контакта.
- Модерация: карточка приходит админу с кнопками «✅ Опубликовать» / «❌ Отклонить».
- Публикация в канал с кнопкой «🐾 Найдено / Вернулся домой».
- Закрытие объявления автором или модератором.
- Хранение объявлений в SQLite (`ads.db`).

## Файлы

| Файл | Назначение |
|------|-----------|
| `bot.py` | основная логика бота |
| `db.py` | работа с базой данных |
| `config.py` | токен, канал, список админов и районов |
| `requirements.txt` | зависимости |
| `ads.db` | создаётся автоматически при первом запуске |

## Установка и запуск

### 1. Подготовка бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`
   и создайте бота. Получите **токен** (уже вписан в `config.py`).
2. Добавьте бота в канал **@malakhovka_in_the_lens** администратором
   (права: публикация и редактирование сообщений).

### 2. Узнайте свой Telegram ID

Запустите бота (см. ниже), напишите ему `/myid` и впишите полученное число
в `config.py` в список `ADMIN_IDS`. Без этого кнопки модерации не будут работать.

### 3. Заполните config.py

- `ADMIN_IDS` — ваш Telegram ID.
- `BOT_USERNAME` — юзернейм бота без `@` (например `malakhovka_lost_bot`).
  Нужен, чтобы в карточке была подпись «Подать объявление: @бот».
- `DISTRICTS` — при необходимости подправьте список районов.

### 4. Запуск

```bash
pip install -r requirements.txt
python bot.py
```

Бот работает в режиме long polling (постоянный опрос). Для продакшена
рекомендуется запускать на сервере/VPS под systemd или в Docker, либо
использовать webhook.

## Как пользоваться

**Для подписчиков:** написать боту `/start`, затем «🔴 Потерялся» или «🟢 Нашёлся»
и следовать вопросам.

**Для модератора:** на заявку приходят кнопки — жмите «✅ Опубликовать» или
«❌ Отклонить».
